## 저장 방식

기록(경비 · 체크리스트 · 일정 변경 · 기차 예약 · 환율)은 **브라우저의 localStorage** 에 저장됩니다.

- 기기·브라우저별로 따로 저장됩니다 — 여러 사람이 같은 주소를 봐도 서로의 기록은 보이지 않습니다
- 브라우저 데이터를 지우면 사라지므로, 경비 탭의 **📋 백업 복사** 로 주기적으로 백업하세요
- 다른 기기로 옮길 때도 **백업 복사 → 📥 백업 붙여넣기** 를 쓰면 됩니다
- 일정 편집은 원본을 덮어쓰지 않는 **덧씌우기 방식**이라 언제든 「원래대로」 되돌릴 수 있습니다

## 좌표

명소 좌표는 OpenStreetMap Nominatim 으로 조회(2026-08-04, 식당·카페 추가분 2026-08-08)해
도시 경계로 검증한 값입니다. 식당 탭의 도보 소요시간은 저장된 좌표 사이 직선거리로 검산했습니다.

**검색어 91곳 전부에 좌표가 붙어 있습니다.** 🧭 길찾기와 📌 좌표는 좌표로 정확히 열리고,
🗺️ 지도 버튼은 구글이 공식 지원하는 `…/maps/search/?api=1&query=이름` 형식만 씁니다
(웹·안드로이드·iOS 앱 공통으로 동작이 보장되는 형식).

동명 업소가 있는 곳은 URL 형식이 아니라 **검색어에 거리명을 넣어** 구분합니다 —
프라하 `Kantýna`·`V Zátiší` 는 4구에 같은 이름이 또 있어 이름만으로는 5~7km 어긋났습니다.
검색어를 바꿀 때는 실제로 구글지도에서 열어 좌표가 맞는지 확인하세요.
지도 **그림 데이터는 포함되어 있지 않습니다** — 데이터 없이 쓰려면 구글지도 앱에서
부다페스트 · 비엔나 · 프라하+드레스덴 오프라인 지도를 미리 내려받아 두세요.

## 휴대폰에 앱으로 설치

- **아이폰**: 사파리로 열기 → 공유 → 홈 화면에 추가
- **안드로이드**: 크롬으로 열기 → 메뉴 → 홈 화면에 추가

주소창 없는 전체화면으로 실행됩니다.
