## 저장 방식

기록(경비 · 체크리스트 · 일정 변경 · 기차 예약 · 환율)은 **브라우저의 localStorage** 에 저장됩니다.

- 기기·브라우저별로 따로 저장됩니다 — 여러 사람이 같은 주소를 봐도 서로의 기록은 보이지 않습니다
- 브라우저 데이터를 지우면 사라지므로, 경비 탭의 **📋 백업 복사** 로 주기적으로 백업하세요
- 다른 기기로 옮길 때도 **백업 복사 → 📥 백업 붙여넣기** 를 쓰면 됩니다
- 일정 편집은 원본을 덮어쓰지 않는 **덧씌우기 방식**이라 언제든 「원래대로」 되돌릴 수 있습니다

## 좌표

명소 좌표는 OpenStreetMap Nominatim 으로 조회(2026-08-04, 식당·카페 추가분 2026-08-08)해
도시 경계로 검증한 값입니다. 식당 탭의 도보 소요시간은 저장된 좌표 사이 직선거리로 검산했습니다.

**검색어 88곳 전부에 좌표가 붙어 있습니다.**

**일정 · 장소 · 식당 세 탭 모두** 🗺️ 는 이름으로 검색해 **이름·영업시간·평점이 바로 보이고**,
**📍** 는 저장된 좌표로 열려 **검색 실패가 없습니다** (`…?api=1&query=위도,경도`).
🧭 길찾기도 좌표 기준입니다. 이름 검색이 실패하거나 다른 지점이 나오면 📍 로 우회하면 됩니다.

이름 검색은 실패할 수 있으므로 검색어를 **`SQ` 표**(`q` → 구글이 찾는 이름)로 따로 둡니다 —
좌표 조회 키인 `q` 는 건드리지 않습니다(GEO 키와 짝이라 바꾸면 좌표가 깨집니다).
**검색어 78곳을 실제 구글지도에서 전수 검증**했습니다(2026-08-10).
이름 검색이 아예 안 되는 2곳(`Danube river cruise`·`Theaterplatz, Dresden`)은
`NOSRCH` 에 넣어 🗺️ 도 좌표로 엽니다.

검색어 규칙은 실측으로 정했습니다 — ① 꼬리의 영문 도시명을 떼고(`Gozsdu udvar Budapest` ✗ →
`Gozsdu udvar` ✓) ② 지점이 여럿이면 거리명을 붙이고(`Figlmüller` → 2호점이 먼저 ✗ →
`Figlmüller Wollzeile` ✓) ③ 발음기호를 살린 원어명을 씁니다. 자세한 내용과 검증 방법은
`TODO.md` 에 있습니다.

지도 **그림 데이터는 포함되어 있지 않습니다** — 데이터 없이 쓰려면 구글지도 앱에서
부다페스트 · 비엔나 · 프라하+드레스덴 오프라인 지도를 미리 내려받아 두세요.

## 하루 동선 보기

일정 탭에서 날짜를 펼치면 **🎬 이 날 동선 그려보기**가 있습니다. 두 가지로 볼 수 있습니다.

- **🗺 실제 지도** — Leaflet + OpenStreetMap 타일 위에 경로·번호 마커를 그리고 ▶ 재생하면 순서대로 이동합니다.
  **타일 그림은 인터넷이 필요합니다.**
- **📐 관계도** — 좌표만으로 그리는 SVG. **오프라인에서도 동작**하며, 200km 넘게 벌어지는 구간은
  가로 띠로 나눠 각자 축척으로 그려 시내 이동이 뭉개지지 않게 합니다.

두 방식 모두 구간 거리와 총 이동거리를 함께 보여줍니다. 선은 **직선 연결이라 실제 도로가 아닙니다** —
길이 필요하면 **📍 지도에 모두 표시**로 구글지도를 여세요.

Leaflet 은 `vendor/` 에 넣어 CDN 없이 저장소에서 직접 불러옵니다(지도를 처음 열 때만 로드).

```

icon-180.png           아이폰 홈 화면 아이콘

```

## 휴대폰에 앱으로 설치

- **아이폰**: 사파리로 열기 → 공유 → 홈 화면에 추가
- **안드로이드**: 크롬으로 열기 → 메뉴 → 홈 화면에 추가

주소창 없는 전체화면으로 실행됩니다.
